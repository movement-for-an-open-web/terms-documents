# Changes from version 2 to version 3

This page lists every clause that changed between [version 2](2.txt) and
[version 3](3.txt) of the Search Only Contract (SOC). For each clause, the
version 2 wording starts with a minus sign and is shown in red, and the
version 3 wording starts with a plus sign and is shown in green. Changes to
spacing and line breaks are not shown.

Version 3 spells “Licenced” and “Unlicenced” with a c throughout, where
version 2 mixed “Licensed” and “Licenced”, and spells the verb “licences”.
Clauses where that is the only change are not listed.
