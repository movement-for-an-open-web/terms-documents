# Agents

Instructions for AI agents and other automated tools working in the `socw`
folder. Also follow `AGENTS.md` at the root of the repository.

## Language

Use British English. The Search Only Contract is specific to the United Kingdom
and its documents are written in British English.

Keep the wording of the contract and its supporting documents as the drafting
lawyers supplied it, including their spelling.

## Version changes

`Search Only Terms Contract.docx` holds the text of the latest numbered version
with one paragraph per clause. Use it as the starting point for the next version
and send it to whoever drafts the change. When the new version is added, replace
the Word file so its text matches the new numbered file exactly.

When a new numbered version of the contract is added, also add a page named
`diff-<old>-to-<new>.md`, for example `diff-2-to-3.md`. It is written for
lawyers. It lists each clause that changed, with the old wording in red and the
new wording in green in a `diff` code block. Changes to spacing and line breaks
are left out.
