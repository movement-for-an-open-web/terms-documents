# Agents

Instructions for AI agents and other automated tools working in this
repository.

## Language

Each document folder has its own `AGENTS.md` stating the variant of English it
uses. `socw` uses British English because the Search Only Contract is specific
to the United Kingdom. `mtm` uses US English because the Model Terms for
Marketing form a single global contract. Match the variant of the folder being
changed. Use British English for text outside those folders, including this
file, the root README, commit messages and pull requests.

Keep the wording of legal and supporting documents as the drafting lawyers
supplied it, including their spelling. "Licencing" stays as written. Raise a
suspected error with a person rather than changing it.

## Version numbers

Numbered documents such as `socw/2.txt` never change once published. A new
version takes the next number, for example `socw/3.txt`. Do not edit earlier
numbered documents or rewrite the git history.

## FAQ source

`socw/README.md` is the published FAQ. A Word version of the same text is kept
as `socw/Search Only Terms Contract FAQ.docx`, with no date in the name. Use it
as the starting point for every future change to the FAQ, and send it to
whoever drafts the change. Make the change in the Word file, update
`socw/README.md` to match, and keep the same file name.

## Word sources

Where a document is published as a PDF, keep its Word source beside it under the
same name, for example
`socw/Guide to Small Claims via Money Claims Online.docx`. Make changes in the
Word file and export the PDF from it.

## Template documents

Pro forma letters and guides are templates for publishers to use. They carry no
law firm or individual branding, names, comments or tracked changes. In Word
files set the author, last modified by and company to Movement for an Open Web
wherever those fields are present, and set the dates to the day the file is
prepared.
